# FCE Prep

DECA Financial Consulting (FCE) 2026-27 prep app. Live: https://m14mason.github.io/fce-prep/

- **Today**: countdown, readiness score, adaptive daily to-do, focus timer
- **Plan**: 8-week plan to districts; weekly target learns from the time you actually log
- **Learn**: 13 Instagram-story lessons (100 animated scenes), 5 slider labs, quiz after each
- **Exam**: 149 questions, blueprint-weighted smart practice, reworded retries, timed mocks, mistake notebook, AI question generator
- **Pitch**: rubric-based script builder, 15:00 paced run timer, audio recorder, pace + filler counter, teleprompter, self-score history, Q&A drill
- **AI Judge**: role-play client (normal / hard), rubric scoring (bring your own Anthropic key, stored only in your browser)
- **Deck studio**: analyze your slides from a Google Slides/Canva link, PDF or screenshots (on-device quick check + AI judge score, slide-by-slide), 11-slide blueprint, 3 blank Canva-ready .pptx templates
- **Tools**: exit-option calculator (net to owner after fees + tax), retirement gap calculator, PI checklist, formula sheet, glossary search
- **Play**: daily challenge, 60-sec speed round, match game, 30-sec opener sprint, competition-day simulation, weak-concept replay
- **Trophies**: XP, levels, 16 badges
- **Pitch extras**: on-device script analyzer, script versions, random/AI client persona, printable leave-behind, video practice with mirror view, narrated story lessons, Ctrl/Cmd+K search
- **Cards**: spaced-repetition flashcards
- **Sync**: copy/paste sync code or private GitHub Gist auto-sync

No build step. Plain HTML/CSS/JS + GSAP. Works offline as a PWA.
